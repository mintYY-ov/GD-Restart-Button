# Restart Button
A cool mod :D

<img src="logo.png" width="150" alt="the mod's logo" />

## What is this?
A mod that adds a button to the main menu that restarts the game.

## Build instructions
You need the Geode CLI set up.

For info on how to install it, see [the Geode docs](https://docs.geode-sdk.org/getting-started/create-mod#build)
```sh
geode build
```
